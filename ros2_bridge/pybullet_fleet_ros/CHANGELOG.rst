Changelog for package pybullet_fleet_ros
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

0.1.2 (2026-08-01)
------------------
* Add ``fleet_demo.launch.py`` for a configurable fleet-only ROS API demo that runs from an installed Jazzy package.
* Add an optional lightweight RViz fleet view driven by the batched Fleet API state stream.
* Install a fleet navigation demo client that offsets every selected robot from its current position.
* Use the PyBullet-provided Franka Panda model in the arm trajectory demo.

0.1.1 (2026-08-01)
------------------
* Update bridge configurations for the fleet-level interface and Jazzy demos.
* Refresh simulation service behavior for the current PyBulletFleet core.

0.1.0 (2026-07-26)
------------------
* Initial release of the PyBulletFleet ROS 2 bridge.
